# Reelcut Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Qt Quick desktop app for Omarchy that edits 9:16 reels (cut, captions, color, music) and exports IG/TikTok-ready MP4s through ffmpeg.

**Architecture:** Pure C++ units (model, export graph, captions, silence parsing, whisper parsing) are unit-tested without a display. A `Backend` QObject owns the project, snapshot-based undo, and background `QProcess` jobs, and is handed to QML. QML owns layout: media/timeline, a 9:16 preview that plays the edit with `MediaPlayer`, approximates the look with `MultiEffect`, and draws captions/overlays as layers.

**Tech Stack:** C++17, Qt 6.12 (core, gui, qml, quick, quickcontrols2, multimedia, network, dbus), qmake6, ffmpeg/ffprobe CLI, whisper-cli (optional), Qt Test.

## Global Constraints

- Output: 1080×1920, 30 fps, H.264 (`h264_nvenc`, fallback `libx264`), AAC 48 kHz stereo, `-movflags +faststart`, loudness `loudnorm=I=-14`.
- Silence detect: `-35dB`, minimum 0.4 s, padding 0.1 s kept on each side.
- Speed range 0.25–4.0; zoom 1.0–3.0; pan -1..1; caption vertical position 0..1 of frame height.
- Never modify originals; save `.reel` atomically (`QSaveFile`).
- Every visible string through `qsTr()`/`tr()`; theme accent and rounding from `Theme`; file dialogs through the portal.
- Keys: `?` help, `Q` quit (asks when dirty), Space play/pause, Ctrl+Z / Ctrl+Shift+Z, S split, Delete remove clip, Ctrl+E export, Ctrl+S save, Ctrl+O open, I import.

## Tasks

### Task 1: Scaffold
Copy templates (pro, bin scripts, theme, translator, main, Main.qml, resources.qrc, tests with theme/translator cases, pkgbuild, .gitignore, LICENSE with Omacut attribution). `bin/build` and `bin/test` pass. Commit "Scaffold Reelcut".

### Task 2: Project model (`src/project.*`)
Interfaces:
- `struct Clip { QString path; double in, out, speed=1, zoom=1, panX=0, panY=0; int width, height; bool audio; double sourceDuration; double duration() const; }`
- `struct Word { QString text; double start, end; }` (timeline seconds)
- `struct Overlay { QString text; double start, end, y=0.2; int size=96; QString animation="pop"; }`
- `struct Music { QString path; double volume=0.35, offset=0; bool duck=true; }`
- `struct Look { double exposure=0, contrast=0, saturation=0, temperature=0; QString lut; }`
- `struct Project { QVector<Clip> clips; Music music; QVector<Overlay> overlays; QVector<Word> words; QString captionStyle="highlight"; double captionY=0.68; Look look; QString platform="instagram"; double duration() const; double clipStart(int) const; struct Locate{int index; double source;}; Locate locate(double t) const; bool split(double t); QJsonObject toJson(QString baseDir) const; static Project fromJson(QJsonObject, QString baseDir); }`
- `replaceClipWithRanges(int index, QVector<QPair<double,double>> ranges)` for silence cut.
Tests: duration with speed, locate across boundaries, split at mid/edge (edge no-op), JSON round trip with relative paths.

### Task 3: Silence (`src/silence.*`)
- `QVector<QPair<double,double>> parseSilences(const QByteArray &log)` (unterminated silence ends at +inf)
- `QVector<QPair<double,double>> keepRanges(double start, double end, silences, double padding=0.1, double minKeep=0.15)`
Tests: real log sample, padding merge, trailing silence.

### Task 4: Captions (`src/captions.*`)
- `struct CaptionLine { double start, end; QVector<Word> words; }`
- `QVector<CaptionLine> groupLines(const QVector<Word>&, int maxWords=3, int maxChars=18, double maxGap=0.6)`
- `QString assTime(double)` → `H:MM:SS.cc`
- `QString assDocument(const Project&, const QString &accentBgr)` styles bold/highlight/pop/box, overlays with fade/pop/slide.
Tests: grouping limits and gaps, time formatting, highlight produces one event per word, braces escaped.

### Task 5: Transcript (`src/transcript.*`)
- `QVector<Word> parseWhisperJson(const QByteArray&)` (segments `offsets.from/to` ms, text trimmed, empty/`[BLANK_AUDIO]` skipped)
Tests: sample JSON.

### Task 6: Export graph (`src/exportgraph.*`)
- `struct ExportOptions { QString output, assFile, lutFile; QString encoder="h264_nvenc"; }`
- `QStringList exportArgs(const Project&, const ExportOptions&)`
- `QStringList timelineAudioArgs(const Project&, const QString &wav)` 16 kHz mono
- `QString framingFilter(const Clip&)` scale+crop math; `QString atempoChain(double)`
Tests: framing for landscape/portrait/zoom/pan, atempo for 0.25/2.5/4, music+duck graph pieces, silent clip uses anullsrc, neutral look adds no eq, end-to-end export of a generated test clip probes 1080×1920 with audio.

### Task 7: Jobs + media + thumbnails
`Job` runs a program, parses `out_time_us=` progress against a known duration, exposes `progress`, `cancel()`, `finished(bool ok, QByteArray stdout, QByteArray stderr)`. Media probe and thumbnails from Omacut.

### Task 8: Backend
Properties and invokables listed in the spec's Units section; snapshot undo (`QVector<QJsonObject>` with a cap of 200), dirty flag, atomic save, portal picks, transcription pipeline (timeline wav → whisper-cli → words), model download to `~/.local/share/reelcut/models/ggml-base.bin` via `QNetworkAccessManager`, silence cut, export with NVENC fallback.

### Task 9: QML UI
Main layout, preview with framing math identical to `framingFilter`, safe-zone overlay per platform, timeline with thumbnails, trim handles, playhead, music lane, overlay lane; inspector tabs Clip / Captions / Text / Color / Audio / Export; help overlay; drag-and-drop import.

### Task 10: CLI export, packaging, README, verify
`reelcut export`, PKGBUILD/desktop/icon, README with shortcuts, offscreen screenshot check, `bin/install`.
